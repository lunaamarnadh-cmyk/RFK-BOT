## ⚙️ Environment Variables (Config)

Render, Railway, Heroku, അല്ലെങ്കിൽ ഏതെങ്കിലും Hosting Panel-ൽ ബോട്ട് സെറ്റ് ചെയ്യുമ്പോൾ താഴെ പറയുന്ന **Variables** കൃത്യമായി നൽകുക:

| Variable Name | Required | Example Value | Description |
| :--- | :---: | :--- | :--- |
| **`SESSION_ID`** | ✅ **Yes** | `RFK-BOT~xxxx` | നിങ്ങളുടെ വാട്‌സാപ്പ് സെഷൻ ഐഡി |
| **`OWNER_NUMBER`** | ✅ **Yes** | `917907228818` | ബോട്ട് ഓണറുടെ വാട്‌സാപ്പ് നമ്പർ (Country code സഹിതം, `+` ഇല്ലാതെ) |
| **`PREFIX`** | ❌ No | `.` | കമാൻഡ് പ്രിഫിക്സ് (Default: `.`) |
| **`MODE`** | ❌ No | `public` | ബോട്ട് മോഡ് (`public` അല്ലെങ്കിൽ `private`) |
| **`AUTO_STATUS`** | ❌ No | `true` | ഓട്ടോ സ്റ്റാറ്റസ് വ്യൂ ഓൺ/ഓഫ് ചെയ്യാൻ (`true` / `false`) |
| **`BOT_NAME`** | ❌ No | `乂𝐑𝐅𝐊 𝐁𝐎𝐓乂` | മെനുവിലും മറ്റും കാണിക്കേണ്ട ബോട്ടിന്റെ പേര് |
| **`STICKER_PACK`** | ❌ No | `乂 𝐑𝐅𝐊 𝐁𝐎𝐓 乂` | സ്റ്റിക്കർ പായ്ക്ക് പേര് |
| **`STICKER_AUTHOR`** | ❌ No | `𝐑𝐅𝐊 𝐌𝐎𝐃𝐒` | സ്റ്റിക്കർ ഓതർ പേര് |
